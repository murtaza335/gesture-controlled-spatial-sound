    Input

    Controls

    Hands

    • Right hand · pinch near a sound, move to place it
    • Right hand · swipe left / right to change track
    • Left hand · 1–5 fingers (hold) → Bass, Treble, Pitch, Filter, Reverb
    • Left hand · pinch & drag up / down to change the value
    • Left hand · fist (hold) resets the value

    Mouse mode

    • Click-drag = pinch · wheel = depth
    • Shift + move = left pinch · 1–5 / 0 = left fingers / fist
    • Alt + fast move = swipe
